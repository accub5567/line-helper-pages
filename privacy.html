隱私權政策

適用服務：LINE 驗證碼小幫手（私人使用的小工具，見服務說明）。
生效日期：2026-10-28

1. 讀取哪些 Google 資料

本服務使用 Gmail 唯讀權限（https://www.googleapis.com/auth/gmail.readonly），只為了找出線上服務寄來的驗證信。程式以特定寄件者與時間範圍搜尋，不閱讀其他信件，也不寄信、刪信或修改郵件。

2. 資料怎麼使用

  • 只用來把驗證碼透過第三方工具傳給帳戶擁有者核准的成員。
  • 不出售、不出租、不分享給第三方，不用於廣告，也不用於訓練任何人工智慧模型。
  • 本服務對 Google API 取得資訊的使用與轉移，會遵守 Google API Services User Data Policy，包含其中的 Limited Use 規定。

3. 保存哪些資料、保存多久

  • 不保存完整信件內容。
  • 代碼只在處理期間短暫加密暫存，用於同一次請求失敗時重送，到期即清除。
  • 請求紀錄（LINE 使用者代號、群組代號、處理狀態）在處理結束後 24 小時內刪除。
  • 已核准成員的 LINE 使用者代號在成員使用期間保存，成員被移除後清除。
  • Google 授權憑證只存放在擁有者的電腦與服務的加密設定中，不放在資料庫或公開位置。

4. 資料放在哪裡

服務執行在 Cloudflare，訊息透過 LINE 傳遞。這兩者依各自的條款處理平台層級的資料。

5. 如何撤銷授權

隨時可到 Google 帳戶的第三方存取頁移除「LINE 驗證碼小幫手」，授權會立即失效。

6. 聯絡與變更

本服務僅限帳戶擁有者指定的成員使用，有問題請直接詢問帳戶擁有者。政策若有修改，會更新本頁與生效日期。
